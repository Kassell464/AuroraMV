# AuroraMV V0.1.0 发布说明

发布日期：2026-08-14 ｜ 许可协议：MIT

## 亮点

AuroraMV V0.1 完成了规格定义的完整闭环：**导入一首歌 → 选视觉风格 → 实时预览 → 导出高质量 MV**。
全部 12 个开发里程碑（阶段 0–11）完成，69 项自动化测试通过。

- **音乐驱动视觉**：节拍 / 音量 / 低频 / 节奏实时驱动画面（librosa 预分析）
- **六套系统预设包**：电影镜头 / 极光星云 / 赛博朋克 / 歌词舞台 / 合成波 / DJ 现场
- **动态歌词**：LRC 解析（UTF-8/GBK）+ 生命周期动画（入场/待机/节拍/退场）+ 三套歌词模板
- **可调节效果**：节拍震动 / 闪光 / GPU 粒子（UI 滑杆 + JSON 模板，参数全部可调）
- **所见即所导出**：预览与导出共用同一渲染管线
- **多格式导出**：MP4(H264) / WebM(VP9) / MOV，360p–1440p、24/30/60fps、16:9/9:16/1:1、码率自动/手动
- **全模板化**：歌词 / 背景 / 效果 / 场景四类 JSON 模板（TemplateLoader 统一加载校验）
- **深色高级感 UI**：预设卡片、效果滑杆、导出面板、播放控制、入场动画（概念灵感：Mineradio）

## 已知限制（V0.1）

- **节拍相位偏移**：librosa 节拍相位存在约 0.27s 的整体偏移（第三方库估计特性），
  震动/闪光仍与节拍节奏一致，仅相位略晚；V0.2 计划校准。
- **曲目结束后画面定格**：预览在曲目结束后保持最后一帧；循环播放待后续版本。
- **图片背景模糊、流体背景（Fluid）**：规格后续项，未在 V0.1 实现。
- **无手动时间轴**：场景按曲目时长自动均分（符合 V0.1「不使用传统 Timeline」的定位）；
  时间轴编辑、关键帧、转场见 V0.3 路线图。
- **仅 Windows**：渲染/导出在 Windows 10+ 上开发与验证。

## 路线图（规格第 49 节）

- **V0.2**：视频背景（mp4/webm/mov）、更好的 AI 歌词（faster-whisper）、更多模板（社区包）
- **V0.3**：时间轴编辑器（拖动场景/关键帧/转场）、插件系统（Python/Shader 插件）
- **V1.0**：完整开源生态（模板市场、社区分享、插件 API、跨平台构建）
